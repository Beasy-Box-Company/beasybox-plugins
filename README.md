# Plugins da Beasybox para o Claude Code

Publicado automaticamente pelo CI de `consultores-beasybox` — não edite à mão; a fonte é a pasta `plugin/` daquele repositório.

```
/plugin marketplace add Beasy-Box-Company/beasybox-plugins
/plugin install beasybox@beasybox-plugins
```

Versão atual: 1.2114.0 (consultores-beasybox 8c8f89e).
